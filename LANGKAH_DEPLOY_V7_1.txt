SISTEM KEHADIRAN GURU V7.1 — GUNA DATABASE RENDER LAMA
=======================================================

TUJUAN V7.1
-----------
Versi ini tidak mencipta PostgreSQL baharu. Ia menggunakan database lama
yang sudah aktif dalam akaun Render Free anda.

LANGKAH 1 — DAPATKAN DATABASE_URL
---------------------------------
1. Di Render Dashboard, buka database lama:
   kehadiran-guru-db
2. Cari bahagian Connections atau Info.
3. Salin "Internal Database URL".
4. Jangan kongsi URL tersebut kepada orang lain kerana ia mengandungi
   maklumat sambungan database.

LANGKAH 2 — GITHUB
------------------
1. Cipta repository baharu, contohnya:
   kehadiran-guru-v8
2. Ekstrak ZIP V7.1.
3. Muat naik semua fail dan folder di dalam projek ke repository itu.
4. Commit changes.

LANGKAH 3 — RENDER BLUEPRINT
----------------------------
1. Pilih New > Blueprint.
2. Sambungkan repository kehadiran-guru-v8.
3. Render akan meminta Environment Variables.
4. Isi:

DATABASE_URL
  Tampal Internal Database URL daripada database lama.

INITIAL_ADMIN_USERNAME
  admin

INITIAL_ADMIN_PASSWORD
  Kata laluan pentadbir yang kuat.

INITIAL_ADMIN_EMAIL
  E-mel pentadbir.

INITIAL_TEACHER_USERNAME
  guru

INITIAL_TEACHER_PASSWORD
  Kata laluan awal guru.

INITIAL_TEACHER_EMAIL
  E-mel guru demo.

5. Klik Deploy Blueprint.
6. V7.1 hanya akan mencipta Web Service dan tidak akan mencipta database baru.

SEMAKAN
-------
Selepas status Live, buka:
  https://kehadiran-guru-v8.onrender.com/health/

Paparan yang betul:
  {"status":"ok","database":"connected","version":"7.1"}

LOG MASUK
---------
Gunakan:
- Nama pengguna pentadbir daripada INITIAL_ADMIN_USERNAME
- Kata laluan daripada INITIAL_ADMIN_PASSWORD

PERINGATAN
----------
Database lama mungkin mengandungi jadual daripada versi terdahulu.
Arahan migrate akan menambah atau mengemas kini jadual yang diperlukan.
Akaun sedia ada tidak akan ditetapkan semula kata laluannya.
